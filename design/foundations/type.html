Role rule. The display face (Figtree) is used only for the wordmark, the display/headline roles, titleLarge, and avatar monograms. Everything at 16sp and below — including titleMedium and titleSmall — uses the platform body face (Roboto), so that conversational text feels like the OS rather than like the brand. Two separate roles previously shared one "Screen title · 22" label here, which is what led an implementation to put headlineMedium (24sp) in a small top app bar where M3 specifies titleLarge (22sp).

⚠ Figtree is a variable font, and its fvar default instance is Light 300. Every declared face must carry explicit weight variation settings (FontVariation.Settings(FontVariation.weight(n))). Compose's 3- and 4-argument Font(resId, weight, …) overloads pass no variation settings, so the typeface instantiates at the font's 300 default and every weight renders Light — while still matching the requested weight exactly, so no synthetic bold rescues it. Declare 400/500/600/700 explicitly.

Scale. Sizes follow the M3 baseline type scale (displaySmall 36, headlineLarge 32, headlineMedium 28, headlineSmall 24, titleLarge 22). Any deviation is a deliberate density choice and must be recorded here, not discovered in the code.
